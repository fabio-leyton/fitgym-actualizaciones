# FitGym · actualizaciones

Versiones publicadas de **FitGym** y **FitGym Gimnasio**. Las apps leen
`version.json` al abrirse para avisar cuando hay una versión nueva, y la
descargan desde los *Releases* de este repositorio.

- `build`: número interno de la última versión (versionCode de Android).
- `minBuild`: las versiones con un número menor deben actualizarse para
  seguir usando la app.
